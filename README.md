# PVE Balance Intelligence

基于大数据的多人联机 PVE 游戏平衡性分析系统课程设计。

项目当前阶段采用：

```text
Python 配置驱动模拟数据生成
        |
HDFS 分布式存储
        |
PySpark 离线分析
        |
本地 ADS 导出
        |
Streamlit 可视化
```

## 当前实现重点

1. 使用配置表决定职业、卡牌、武器、地图和发卡规则。
2. 使用脚本批量生成可解释的模拟游戏事件数据。
3. 使用 HDFS 保存 ODS、DWD、DWS、ADS 分层数据。
4. 使用 PySpark 完成职业、地图、卡牌和流派组合分析。
5. 使用 Streamlit 展示离线分析结果。
