# 指标口径与数据字典

## 1. 核心口径

### 1.1 队伍人数

每局随机 `2-10` 名玩家。

### 1.2 地图网格

地图为 `1000x1000` 二维网格：

```text
0 <= x < 1000
0 <= y < 1000
grid_x = floor(x)
grid_y = floor(y)
grid_id = concat(map_id, '_', grid_x, '_', grid_y)
```

ADS 层只保存有事件发生的稀疏网格。Streamlit 展示时可以按 `10x10` 或 `20x20` 区域聚合。

### 1.3 50 波达成率

由于游戏是无限轮次 PVE，不使用传统通关胜率。当前胜率口径定义为全队是否达成 50 波：

```text
match_success = final_wave >= 50
success_50_rate = success_match_count / total_match_count
```

职业、卡牌、流派都围绕 `success_50_rate` 计算收益。

### 1.4 高表现率

高表现率不是只看最终轮次是否进入前 25%，而是综合玩家贡献。

建议表现分：

```text
performance_score =
  0.35 * normalized_damage_dealt
+ 0.25 * normalized_kill_count
+ 0.20 * normalized_heal_done
+ 0.20 * role_survival_adjusted_tank_score
```

同一职业内 `performance_score` 排名前 25% 的玩家记为高表现玩家：

```text
high_performance_rate = high_performance_player_count / total_player_count
```

承伤解释：

| 职业类型 | 口径 |
| --- | --- |
| 坦克 | 承伤通常是贡献，但需要结合生存率或存活轮次 |
| 脆皮输出 | 承伤过高通常是风险，应降低权重或作为惩罚 |
| 治疗/辅助 | 主要看治疗量、辅助贡献和存活，不以承伤为主 |

### 1.5 卡牌选取率

卡牌选取率需要同时记录 `card_choice` 和 `card_pick`：

```text
pick_rate = pick_count / max(show_count, pick_count)
```

`show_count` 表示卡牌出现在候选池的次数，`pick_count` 表示卡牌被选择的次数。
当模拟数据出现选择次数大于候选曝光次数时，ADS 使用 `effective_show_count = max(show_count, pick_count)` 作为分母，避免选取率超过 100%。

### 1.6 卡牌强度分析口径

卡牌强度不只看最终是否携带，还需要区分“出现、选择、生效、收益”四层：

| 层级 | 说明 |
| --- | --- |
| 曝光层 | 卡牌是否出现在候选池，依赖 `card_choice` |
| 选择层 | 玩家是否选择该卡牌，依赖 `card_pick` |
| 生效层 | 卡牌如何改变玩家属性、武器状态或全局词条 |
| 结果层 | 对 50 波达成率、平均轮次、伤害、击杀、治疗、承伤的影响 |

卡牌类型：

| 类型 | 分析重点 |
| --- | --- |
| `permanent_buff` | 长期属性收益，适合看平均轮次提升 |
| `instant_effect` | 生存救急价值，适合按低血量或高危险轮次分组 |
| `new_weapon` | 是否解锁关键流派，适合看后续卡牌组合 |
| `weapon_upgrade` | 武器成长曲线和边际收益 |
| `global_affix` | 后期风险收益比，需要同时看正收益和负面代价 |

卡牌强度分析至少按职业、轮次阶段、候选曝光和前置条件分层，避免把“强队伍更容易活到后期并拿到强卡”误判为卡牌本身强。

## 2. 关键事件字典

| 事件 | 说明 | 关键字段 |
| --- | --- | --- |
| `battle_start` | 对局开始 | `match_id`、`room_id`、`map_id` |
| `battle_end` | 对局结束 | `match_id`、`final_wave` |
| `player_join` | 玩家加入 | `player_id`、`hero_id` |
| `wave_start` | 轮次开始 | `wave` |
| `enemy_spawn` | 敌人刷新 | `x`、`y`、`enemy_count` |
| `enemy_kill` | 敌人击杀 | `player_id`、`enemy_id` |
| `level_up` | 玩家升级 | `player_id`、`level` |
| `card_choice` | 候选卡牌 | `candidate_card_ids` |
| `card_pick` | 选择卡牌 | `card_id`、`card_type`、`target_weapon`、`build_tags` |
| `position_tick` | 位置采样 | `x`、`y` |
| `player_wave_stat` | 每轮表现 | `damage_dealt`、`kill_count`、`heal_done`、`damage_taken` |
| `player_death` | 玩家死亡 | `death_wave`、`x`、`y` |

## 3. ADS 表口径

### 3.1 `ads_hero_balance_report`

| 字段 | 说明 |
| --- | --- |
| `hero_id` | 职业 ID |
| `use_count` | 使用次数 |
| `avg_survival_wave` | 平均存活轮次 |
| `avg_kill_per_wave` | 每轮平均击杀数 |
| `success_50_rate` | 50 波达成率 |
| `high_performance_rate` | 高表现率 |
| `balance_score` | 综合平衡评分 |

### 3.2 `ads_map_grid_heatmap_report`

| 字段 | 说明 |
| --- | --- |
| `map_id` | 地图 ID |
| `grid_x` | 网格 X |
| `grid_y` | 网格 Y |
| `death_count` | 死亡次数 |
| `stay_duration` | 停留时长 |
| `enemy_spawn_count` | 敌人刷新数量 |
| `danger_score` | 危险系数 |

### 3.3 `ads_card_strength_report`

| 字段 | 说明 |
| --- | --- |
| `card_id` | 卡牌 ID |
| `show_count` | 出现在候选池次数 |
| `effective_show_count` | 选取率计算使用的有效曝光次数 |
| `pick_count` | 被选择次数 |
| `pick_rate` | 选取率 |
| `success_50_lift` | 50 波达成率提升 |
| `wave_lift` | 平均轮次提升 |
| `strength_score` | 综合强度评分 |

### 3.4 `ads_build_combination_report`

| 字段 | 说明 |
| --- | --- |
| `combination_type` | 卡牌组合或职业组合 |
| `items` | 组合内容 |
| `support` | 支持度 |
| `confidence` | 置信度 |
| `lift` | 提升度 |
| `avg_final_wave` | 平均最终轮次 |
| `success_50_rate` | 50 波达成率 |
