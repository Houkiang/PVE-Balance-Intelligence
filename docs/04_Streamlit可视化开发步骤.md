# Streamlit 可视化开发步骤

## 1. 目标

使用 Streamlit 展示 PySpark 离线分析结果。Streamlit 不直接读取 HDFS，而是读取 PySpark 从 ADS 导出的本地 CSV/Parquet 文件。

## 2. 输入数据

默认读取目录：

```text
data/ads_export/
```

推荐文件：

| 文件 | 看板 |
| --- | --- |
| `hero_balance_report.parquet` | 职业平衡 |
| `map_grid_heatmap_report.parquet` | 地图热力 |
| `card_strength_report.parquet` | 卡牌强度 |
| `build_combination_report.parquet` | 流派组合 |

CSV 也可以作为备选，方便调试和答辩展示。

## 3. 页面结构

建议使用侧边栏切换分析主题：

```text
职业平衡
地图难点区域
卡牌强度
流派组合
数据概览
```

## 4. 职业平衡页面

核心图表：

| 图表 | 说明 |
| --- | --- |
| 职业 50 波达成率柱状图 | 判断职业综合强度 |
| 平均存活轮次柱状图 | 判断职业生存能力 |
| 每轮平均击杀数柱状图 | 判断职业输出能力 |
| 高表现率柱状图 | 判断职业玩家贡献上限 |
| 职业平衡评分排行 | 给出综合结论 |

## 5. 地图难点区域页面

地图为 `1000x1000` 二维网格。由于完整网格过大，展示层建议做区域聚合：

```text
display_grid_x = floor(grid_x / 10)
display_grid_y = floor(grid_y / 10)
```

这样可以将 `1000x1000` 降为 `100x100` 展示网格。

核心图表：

| 图表 | 说明 |
| --- | --- |
| 危险系数热力图 | 展示地图难点区域 |
| 死亡次数热力图 | 展示死亡集中区域 |
| 敌人刷新密度热力图 | 展示刷怪压力区域 |
| 危险区域 TopN 表格 | 便于报告引用 |

## 6. 卡牌强度页面

核心图表：

| 图表 | 说明 |
| --- | --- |
| 卡牌选取率排行 | 判断玩家偏好 |
| 50 波达成率提升排行 | 判断实际收益 |
| 平均轮次提升排行 | 判断长期收益 |
| 武器成长曲线 | 展示升级卡牌数值变化 |

需要区分“高选取率”和“高收益”。高选取率可能代表热门，未必代表强度最高。

## 7. 流派组合页面

核心图表：

| 图表 | 说明 |
| --- | --- |
| 高频卡牌组合表 | 展示常见流派 |
| 强势职业组合表 | 展示团队搭配 |
| 支持度、置信度、提升度散点图 | 展示组合关联强度 |
| 组合 50 波达成率排行 | 展示实战表现 |

## 8. 运行方式

推荐命令：

```bash
streamlit run dashboard/streamlit_app.py
```

## 9. 验收标准

1. Streamlit 可以成功启动。
2. 页面能读取 `data/ads_export/` 的结果文件。
3. 至少包含职业、地图、卡牌、流派四个页面。
4. 1000x1000 地图数据展示不卡顿。
5. 图表结论能直接用于课程报告。
