# 文档索引

本目录用于拆分课程设计开发步骤，便于快速阅读和查找。

| 文档 | 用途 |
| --- | --- |
| `01_数据生成开发步骤.md` | 设计和实现模拟游戏事件数据 |
| `02_HDFS数据湖开发步骤.md` | 规划 HDFS 分层目录和数据落盘 |
| `03_PySpark离线分析开发步骤.md` | 实现 DWD、DWS、ADS 离线分析任务 |
| `04_Streamlit可视化开发步骤.md` | 实现职业、地图、卡牌、流派看板 |
| `05_指标口径与数据字典.md` | 固化胜率、高表现率、地图网格、卡牌强度等口径 |
| `06_配置表设计.md` | 固化职业、卡牌、武器、地图和发卡规则配置 |

当前主线方案：

```text
Python 模拟数据生成
        |
本地 JSON Lines
        |
HDFS ODS 原始数据
        |
PySpark 清洗、汇总、分析
        |
HDFS DWD/DWS/ADS Parquet
        |
导出本地 CSV/Parquet
        |
Streamlit 可视化
```
