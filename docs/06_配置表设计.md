# 配置表设计

## 1. 设计原则

数据生成采用配置驱动方案：

```text
配置表 = 游戏规则、数值倾向和权重
生成脚本 = 执行规则的模拟引擎
输出日志 = 模拟对局产生的可分析数据
```

因此职业强弱、卡牌权重、武器成长、地图危险区域和负面词条出现阶段都应优先放在配置文件中。生成脚本只负责读取配置、计算权重、更新状态和输出事件。

## 2. `simulation_config.yaml`

建议字段：

| 字段 | 说明 |
| --- | --- |
| `seed` | 随机种子 |
| `match_count` | 生成对局数量 |
| `player_pool_size` | 模拟玩家池大小 |
| `start_date` | 数据开始日期 |
| `days` | 生成天数 |
| `team_size_min` | 最小队伍人数，当前为 2 |
| `team_size_max` | 最大队伍人数，当前为 10 |
| `target_wave` | 成功目标，当前为 50 |
| `map_width` | 地图宽度，当前为 1000 |
| `map_height` | 地图高度，当前为 1000 |
| `position_tick_seconds` | 位置采样间隔 |
| `global_affix_min_wave` | 负面全局词条最早出现轮次 |

## 3. `hero_config.csv`

建议字段：

| 字段 | 说明 |
| --- | --- |
| `hero_id` | 职业 ID |
| `hero_name` | 职业名称 |
| `role_type` | 职业定位，如 `tank`、`dps`、`healer`、`support` |
| `base_power` | 基础输出系数 |
| `base_defense` | 基础防御系数 |
| `base_luck` | 基础幸运系数 |
| `base_move_speed` | 基础移速系数 |
| `base_heal_power` | 基础治疗系数 |
| `survival_factor` | 生存系数 |
| `damage_taken_role_weight` | 承伤对表现分的权重 |
| `preferred_tags` | 职业偏好流派标签，如 `aoe;staff;defense` |

## 4. `card_config.csv`

卡牌类型：

| 类型 | 说明 |
| --- | --- |
| `permanent_buff` | 永久属性 Buff |
| `instant_effect` | 即时或短时效果 |
| `new_weapon` | 获得新武器 |
| `weapon_upgrade` | 升级已有武器 |
| `global_affix` | 后期出现的带负面效果的全局词条 |

建议字段：

| 字段 | 说明 |
| --- | --- |
| `card_id` | 卡牌 ID |
| `card_name` | 卡牌名称 |
| `card_type` | 卡牌类型 |
| `rarity` | 稀有度 |
| `base_weight` | 基础出现权重 |
| `min_wave` | 最早出现轮次 |
| `max_wave` | 最晚出现轮次，可为空 |
| `target_attr` | 影响属性，如 `power`、`luck`、`move_speed`、`defense` |
| `effect_value` | 正面效果数值 |
| `duration_wave` | 持续轮次，永久卡可为空 |
| `target_weapon` | 影响武器 ID，非武器卡可为空 |
| `upgrade_attr` | 武器升级维度，如 `damage`、`cooldown`、`attack_count`、`frequency`、`range` |
| `negative_attr` | 负面属性，可为空 |
| `negative_value` | 负面数值，可为空 |
| `hero_affinity` | 职业适配权重，如 `mage:1.3;warrior:0.9` |
| `build_tags` | 流派标签，如 `aoe;staff;risk_damage` |
| `prerequisite` | 前置条件，如 `has_weapon:staff` |

卡牌出现权重：

```text
final_weight =
  base_weight
* wave_phase_weight
* hero_affinity_weight
* build_synergy_weight
* prerequisite_weight
* rarity_weight
```

卡牌选择评分：

```text
pick_score =
  base_card_value
+ hero_fit_score
+ build_synergy_score
+ survival_need_score
+ weapon_growth_score
- risk_penalty
+ random_noise
```

## 5. `weapon_config.csv`

建议字段：

| 字段 | 说明 |
| --- | --- |
| `weapon_id` | 武器 ID |
| `weapon_name` | 武器名称 |
| `weapon_tags` | 武器流派标签，如 `staff;aoe;magic` |
| `base_damage` | 基础伤害 |
| `base_cooldown` | 基础冷却 |
| `base_attack_count` | 每轮基础攻击次数 |
| `base_frequency` | 攻击频率 |
| `base_range` | 攻击范围 |
| `aoe_factor` | 范围伤害系数 |
| `damage_growth` | 伤害升级成长 |
| `cooldown_growth` | 冷却升级成长 |
| `attack_count_growth` | 攻击次数成长 |
| `frequency_growth` | 攻击频率成长 |
| `range_growth` | 范围成长 |

武器升级卡只修改武器状态，不直接写死在战斗计算代码里。

## 6. `map_config.csv`

建议字段：

| 字段 | 说明 |
| --- | --- |
| `map_id` | 地图 ID |
| `map_name` | 地图名称 |
| `width` | 地图宽度，当前为 1000 |
| `height` | 地图高度，当前为 1000 |
| `danger_zone_id` | 危险区域 ID |
| `x_min`、`x_max` | 危险区域 X 范围 |
| `y_min`、`y_max` | 危险区域 Y 范围 |
| `death_risk_multiplier` | 死亡风险倍率 |
| `spawn_density_multiplier` | 敌人刷新密度倍率 |
| `stay_bias` | 玩家停留倾向 |

## 7. 验收标准

1. 修改 `card_config.csv` 的 `base_weight` 后，卡牌出现次数随之变化。
2. 修改 `hero_config.csv` 的职业偏好后，该职业候选卡和选择卡发生变化。
3. 修改 `weapon_config.csv` 的成长曲线后，武器类升级卡的收益曲线发生变化。
4. 修改 `map_config.csv` 的危险区域后，死亡热力和刷怪密度发生变化。
5. 生成脚本核心逻辑不需要因为具体数值变化而修改。
